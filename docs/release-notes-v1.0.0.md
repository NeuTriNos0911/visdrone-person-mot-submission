# VisDrone Person MOT Submission v1.0.0

Initial packaged submission for VisDrone person detection and multi-object
tracking.

## Included In Git

- Source code for detection, tracking, dataset conversion, visualization, and
  edge export.
- Runtime and dataset configuration.
- Lightweight tests.
- Validation metrics and preview frames.
- Compact `yolo11n.pt` detector.

## Included As Release Asset

- `VisDrone_Person_MOT_Submission.zip`, the original full submission archive
  with rendered validation videos.
